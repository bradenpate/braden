# Braden Pate portfolio

Static HTML, CSS, and JavaScript served by GitHub Pages from the root of `main` at https://bradenpate.com.

The shared layout uses `site.css`, `content-pages.css`, `heading-scale.css`, and `portfolio-shell.js`. The homepage view toggle lives in `site.js`; About interactions live in `interest-hover.js`. Project artwork stays in `images/work/`.

Preview locally with `python3 -m http.server 8766`. Root HTML and supporting files are mirrored in `src/`; keep both copies synchronized when editing.
